The convergence review loop

One agent reviews. Another addresses the feedback. Repeat until clean.

We put agents in a loop around the pull request. A reviewer agent reviews it. An author agent addresses the findings. The reviewer reviews again.

The loop converges: each round has fewer findings, until a review comes back clean. Then the PR merges.

To begin with

At first, human eyes go on the code.

Not to approve each PR, but to assess the quality of the automated loop. You're judging the reviewer, not the change.

  • Is this review letting in code that erodes the safety of the codebase?
  • Are duplicate implementations appearing?
  • Does a PR that passed review fail in integration or production?

Attention steps down as trust in the loop is earned. Each escape sends eyes back to the code, and then into tuning the loop.

Why duplication matters

Duplicate implementations cause whack-a-mole.

Three PRs each passed review, and each added its own way to calculate an order total. Nobody noticed, because each one was fine on its own.

Then a rounding bug shows up in a user report. You fix it. Another report arrives about the same bug, somewhere else. Then another. One defect, many bug reports.

A review loop that lets duplication in is quietly multiplying future bugs.

When something escapes

Tune the reviewer's whole environment, not just the reviewer.

The obvious targets are a stronger model and a better prompt. They help, but they're not enough on their own.

We also need to address the context the reviewer works in, and the structural guardrails around it. The strongest fix makes the defect impossible, so no reviewer has to catch it.

We're engineering the environment to tune the entire system.

The real question

Not “does it work?”, but where it works and where it fails.

Zero-eyes approval isn't a switch you flip for the whole codebase. It works well for some kinds of change, in some parts of the code, and fails for others.

Map it. Then engineer the system to fix the failures, one class at a time, and watch the map turn green.
